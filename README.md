# Niche Research

An n8n-powered research tool that finds in-demand digital product niches by combining:

1. **Reddit**: what people want (problems, requests)
2. **Pinterest**: what people search (trends, volume)
3. **Etsy / Gumroad**: where people pay (sales proof, prices, competition)

Each niche gets a score: need + search demand + proof of payment - competition.

Work is tracked in GitHub Issues, one milestone per phase.
